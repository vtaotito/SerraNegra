# Portal Web — Cockpit

SPA (React/Next.js + TypeScript) com design system (ex.: Fluent UI): topbar (período, busca, Chat/IA, Bookmarks, status atualização), sidebar (Home, Comercial, Clientes, Produtos, Estoque, Carteira, Margens, Qualidade de Dados, Admin). Filtros globais persistentes em drill-through; KPI cards, rich table, drill-through drawer; skeleton loaders e empty states; bookmarks que salvam e reabrem visão com os mesmos filtros.

Módulos: Home (visão executiva), Comercial, Clientes, Produtos, Estoque, Carteira, Margens & CMV, Qualidade de Dados, Admin & Governança.
