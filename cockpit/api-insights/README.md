# API de Insights

Endpoints para:

- **drivers** — Decomposição de variação (preço, volume, mix, custo) por KPI e nível
- **anomalies** — Detecção robusta (z-score/MAD, mudança de regime) por KPI e nível
- **forecast** — Série temporal com intervalo de confiança e premissas
- **narrative** — Resumo executivo (opcional)

Consumida pelo front e pelo serviço de IA para respostas grounded.
